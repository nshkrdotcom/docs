The missing layer was the mechanism.

This probe asks whether a person can move from a requirement to the state, concurrency, failure boundaries, and source needed to fulfill it—and notice machinery whose justification is missing.

What I reread

The original BEAM Atlas notes in brainstorms/nshkrdotcom/docs/20261010/beam_atlas/: 0004, 0005, 0006, 0006a, and 0007; the blueprint product thesis, semantic identities, projection catalogue, state model, and OTP causality model.

0004 asks “why does each process exist?” 0005 introduces abstraction envelopes. 0006 rejects a universal semantic tree. 0006a separates declared intent from inferred purpose. 0007 explicitly abandons four equal panels for an adaptive focus canvas.

Three directions considered

3D code city: spatial landmarks, but file height says little about guarantees or unnecessary state.

Architecture matrix: useful for coupling at large scale, but weak at explaining one actor.

Intent / machinery atlas: chosen for this probe. Two distinct projections, an inspectable correspondence, and local cross-sections with source embedded in context.

Research grounding

Software Reflexion Models compare a supplied high-level architecture with mapped source relationships. The mapping is explicit; agreement is not a behavioral proof.

Code Canvas puts source and visual layers on a zoomable surface. This probe borrows contextual source navigation rather than a docked editor.

Elixir’s GenServer guidance ties processes to runtime needs such as state, concurrency, and failure isolation. A module boundary alone is insufficient justification.

What the wireframe proposes

Depth represents distinct ownership / lifetime boundaries; it does not pretend software has one geometric hierarchy. “Peel” separates the same boundaries; “Open actor” changes the abstraction and visual grammar.

The simpler proposal removes several actor wrappers, but keeps the durable store, effect boundary, and inherited dependency machinery visible. It is incomplete and has no equivalence evidence.

What we should judge

Can you tell why a process exists? What dies with it? What survives? Which promise is at risk? Can you reach the relevant source without memorizing file paths? Does the spatial cross-section help, or is it decoration?

Intentionally omitted: capture, real indexing, AI inference, editing, full dependency expansion, freely orbitable 3D, polished animation. This is a review artifact for the navigation concept.
