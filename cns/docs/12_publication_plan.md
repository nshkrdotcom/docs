# 12 — Publication and Research Program Plan

## Paper 1: system and theory

**Title:** Grounded Chiral Tensor Synthesis: Proof-Carrying Multiverse Views for Narrative Resolution under Limited Information

Core claims:

1. Define language–logic chirality.
2. Define possible-world narrative synthesis.
3. Show oracle-boundary discipline.
4. Provide experiments on synthetic latent contexts and fact verification.

Required results before submission:

- synthetic latent-context experiment;
- SciFact/FEVER grounding experiment;
- ablation against RAG/debate;
- calibration table;
- proof trace examples;
- error analysis.

## Paper 2: chirality metric

**Title:** Language–Logic Curvature Predicts Synthesis Difficulty in Evidence-Grounded Claim Resolution

Core claim: evidence-weighted chirality predicts failure/difficulty better than embedding distance or graph cycles alone.

## Paper 3: oracle boundary and calibration

**Title:** Training with Oracles, Running without Oracles: Calibrated Possible-World Inference for Undersupervised Synthesis

Core claim: labels can calibrate a runtime system without becoming a runtime crutch.
