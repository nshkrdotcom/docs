# 12 — Publication and Research Program Plan

## Paper 1: system and theory

**Title:** Grounded Chiral Tensor Synthesis: Access-Aware Multiverse Views for Likely-Truth Ranking under Limited Information

Core claims:

1. Define language–logic–access chirality.
2. Define possible-world narrative synthesis.
3. Define strict proof support, likely-truth posterior, and confidence as separate outputs.
4. Show oracle-boundary discipline.
5. Provide experiments on synthetic latent contexts, fact verification, and adversarial record access.

Required results before submission:

- synthetic latent-context experiment;
- synthetic adversarial-record experiment;
- SciFact/FEVER grounding experiment;
- ablation against RAG/debate;
- calibration table;
- proof trace examples;
- record-access examples;
- error analysis.

## Paper 2: chirality metric

**Title:** Language–Logic–Access Curvature Predicts Synthesis Difficulty in Evidence-Grounded Claim Resolution

Core claim: evidence-weighted and access-aware chirality predicts failure/difficulty better than embedding distance or graph cycles alone.

## Paper 3: oracle boundary and calibration

**Title:** Training with Oracles, Running without Oracles: Calibrated Possible-World Inference for Likely-Truth Ranking

Core claim: labels can calibrate a runtime system without becoming a runtime crutch.

## Paper 4: adversarial evidence

**Title:** Access-Aware Inference for Adversarial Evidence Environments

Core claim: record-access modeling improves likely-truth ranking when decisive records are missing, controlled, unavailable, or affirmatively non-supportive.
