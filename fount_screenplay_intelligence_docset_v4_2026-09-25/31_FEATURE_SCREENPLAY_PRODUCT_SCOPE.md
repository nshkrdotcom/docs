# Feature-Screenplay Product Scope

## 1. Scope decision

This implementation program targets **feature-film screenplays**.

That is an intentional product boundary, not a missing capability discovered by the review.

## 2. Why the boundary matters

Episodic television and series development introduce requirements that are not merely longer versions of feature-film analysis:

- episode/season/series arc hierarchy;
- episodic reset versus serialization;
- act-outs and commercial/network structures where applicable;
- cold open / teaser / tag conventions;
- writers-room ownership/provenance;
- series-bible facts;
- cross-episode continuity;
- recurring status quo and promise management;
- season-level reader/viewer memory;
- episode-specific production constraints.

Adding those concepts would dilute feature-film acceptance criteria and require different corpus/evaluation design.

## 3. What feature-film scope includes

The program should handle feature films with unconventional forms, including:

- non-linear chronology;
- multiple protagonists;
- ensemble structures;
- unreliable narration;
- dream/hypothetical/alternate material;
- anthology-like internal segmentation;
- genre hybrids;
- deliberate structural rule-breaking.

Unusual feature structure is not the same thing as television support.

## 4. No future-compatibility tax

Do not add abstraction solely to preserve hypothetical future TV compatibility.

If future product requirements add episodic/series intelligence, define it explicitly and decide then whether it belongs in these packages or a separate composition.

## 5. Evaluation population

Human/domain validation for this program should recruit and evaluate against people/material relevant to feature screenplays:

- feature screenwriters;
- feature script readers/analysts;
- story editors/development professionals where appropriate;
- first-time feature-script readers for Reader studies.

Do not claim validation for episodic/TV use from feature-film results.
