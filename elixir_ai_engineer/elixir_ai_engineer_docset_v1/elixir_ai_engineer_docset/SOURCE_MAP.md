# Source Map

This docset synthesizes the following provided material and conversation themes:

1. **Designing Elixir Systems with OTP outline** — especially the layered “Data, Functions, Tests, Boundaries, Lifecycles, Workers” framework, the warning against defaulting to GenServers, pure functional core, thin boundaries, supervision, workers, and boundary testing.
2. **Spec compiler / AI engineering brainstorms** — especially SpecCells, Engineering Normal Form, implementation graph extraction, context bundles, AccessGraph/capability substrate, credentialed effects, and the claim that accepted code should be an admissible projection of structured specs.
3. **Community critique thread** — especially the point that greenfield SDK/system design is hard for agents because there is no implicit context that prunes bad nonfunctional choices, plus the senior Elixir criticism that plausible AI code can be much larger and worse than a human rewrite.

The docset is a proposed architecture, not a claim that all described tooling already exists.
